# P-25 Cracker — Official Website

GitHub Pages-ready landing site for **P-25 Cracker**, built exclusively for
**HRIT University's B.Pharm 2025 Batch**.

## What's in this build
- Redesigned UI (new navy/gold theme, Sora display type, bento feature grid)
- New official logo (`assets/p25-logo.png`, `assets/favicon-512.png`, `assets/apple-touch-icon.png`)
- Intro splash screen (`assets/video/splash-desktop.mp4` / `splash-mobile.mp4`) that
  automatically plays the right video for desktop vs. mobile screens, with a
  "Skip intro" button and a safety timeout so it can never trap a visitor
- Working APK download at `downloads/P25-Cracker.apk`
- "Built exclusively for HRIT University — B.Pharm 2025 Batch" mentioned in the
  top ribbon, hero, download section and footer

## Before publishing
- The bundled APK (`downloads/P25-Cracker.apk`) is a **debug build** — swap in
  your signed release build before sharing widely.
- Replace `YOUR-GITHUB-USERNAME` in `robots.txt` and `sitemap.xml`.
- Optional: re-export the splash videos at a lower bitrate if you want a
  faster first load on slow mobile connections.
